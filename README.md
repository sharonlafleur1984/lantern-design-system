# Lantern design system

Lantern is one design system with a theme for each of Sharon's products. This repo holds its plan and docs: the [wiki](https://github.com/sharonlafleur1984/lantern-design-system/wiki), the [issues](https://github.com/sharonlafleur1984/lantern-design-system/issues) and the [project board](https://github.com/users/sharonlafleur1984/projects/8). The code is kept private.

See every component live in [Storybook](https://lanterndesignsystem.netlify.app/).
